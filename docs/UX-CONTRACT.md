# 공통 UI 동작

사용자 요구사항과 현재 프론트엔드 예시 데이터 계약을 기준으로 한다. 시각 기준은 [DESIGN.md](DESIGN.md), 예시 데이터 범위는 [README.md](../README.md) 및 [src/data/index.js](../src/data/index.js)가 소유한다.

## Canonical UI Map

| 기능 | 소유 컴포넌트 | 동작 |
|---|---|---|
| 검색 및 검증 | Header / MainPage.search | 명시적 제출, 한국어 IME 조합 중 제출 방지, 오류와 입력 연결 |
| 검색 지우기 | Header / MainPage.home | 즉시 초기 안내로 복귀, 오류·결과 삭제, 조건 유지, 입력 포커스 복원 |
| 거리·난이도 | DistanceControl / DifficultyControl | 최소≤최대, 3~20km, 슬라이더와 숫자 입력 동기화 |
| 목록·상세·순위 | MainPage / RouteCard / RouteDetail / RegionRanking | 지역·탭·상세 전환과 재추천 시 스크롤 맨 위로 이동 |
| 모바일 화면 | MainPage | 목록/지도 전환, 코스 상세를 열면 목록 화면으로 이동 |
| 사이드바 너비 | ResizableSidebar | 데스크톱에서 경계 드래그 또는 좌우 방향키로 조절, 320~560px, 지도에 최소 420px 확보, 더블클릭/Enter로 390px 복원 |
| 안내 모달 | Modal | 첫 버튼 포커스, 배경 inert, Tab 순환, Escape 닫기, 닫은 뒤 트리거 포커스 복원 |
| 스크롤바 | src/styles.css | 전역 색상 및 보이는 스크롤바, 목록의 안정적 공간 확보 |
| 순위 지도 표시 | regionLabelLayout / 지도 제공자 | 실제 좌표의 간결한 핀, 상위 순위 우선 충돌 회피, 클릭 시 코스 추천, 전체 목록 유지 |
| 지도 오류 | 지도 제공자 컴포넌트 | 오류 텍스트, 네이버 연결 실패 시 다시 연결 버튼 |
| 지도 줌 간격 | naverZoomController / LeafletMapView | 확대·축소 한 번에 0.5, 네이버 이미지 타일 모드에서는 정수 줌과 화면 배율 조합으로 반 단계 제공 |
| 지도 줌 모션 | naverZoomController | 지도 전체 복제 레이어 제거. 벡터는 SDK 줌 효과 사용. 이미지 타일은 실제 지도 렌더 영역을 2배로 고정하고 250ms 배율 전환, 정수 타일 단계 변경 시 현재 화면 배율 보정으로 연결. 순위 핀 충돌 검사는 실제 보이는 영역 기준. reduced-motion에서는 즉시 전환 |
| 지역 선택 이동 | naverZoomController / naverCourseViewport | 지역 선택·순위 복귀·전체 코스 보기는 현재 중심과 배율에서 약 1100ms 동안 부드럽게 이동·확대/축소. 실제 보이는 영역과 지도 카드 여백에 코스를 맞춤. 연속 선택은 현재 위치에서 새 목적지로 연결하며 드래그·줌 입력과 언마운트 시 이전 이동 취소. 첫 로딩과 reduced-motion은 즉시 표시 |
| 네이버 렌더링 | loadNaverMaps / NaverMapView | 기존 이미지 타일 화면을 유지하고 정수 타일 줌과 연속 화면 배율을 조합. 지연 GL 로드에 따른 줌 의미 변경을 방지하도록 GL 서브 모듈을 요청하지 않음 |
| 지도 마커 크기 | naverZoomController / NaverMapView | 출발·도착 라벨, 코스 번호, 경유점, 방향 화살표, 지역명 핀은 줌에 관계없이 화면 크기를 유지. 반 단계 CSS 줌 및 지역 이동의 매 프레임에 표시 배율의 역수를 적용하며 마커 기준점은 실제 좌표에 고정 |
| 지도 표시 범위 | naverViewportBounds / LeafletMapView | 줌 6~17 허용. 네이버 지도는 중심점의 위도 32.5~39·경도 124~130.5를 제한하며 화면 가장자리는 범위 밖도 보일 수 있음. 저배율에서 중심점 이동 범위를 화면 크기로 축소하지 않음 |

## 상태 유지

지역 검색·탭 이동·검색어 삭제 시 거리와 난이도를 유지한다. 현재 조건 및 선택은 페이지 내부 상태이며 새로고침하면 초기화된다. 프로토타입에 URL 상태 공유는 아직 제공하지 않는다.

## 데이터와 오류

현재 경로는 도로를 따라 계산한 실제 경로가 아니다. 점수·거리·시간·지표는 예시 생성 결과이며 실제 주행 가능성을 판정하지 않는다. 미지원 검색에는 지원 예시와 수정 방향을 보여준다. 검색어 지우기는 오래된 오류와 결과도 함께 지운다. 외부 추천 요청이 없으므로 원격 검색 debounce·취소는 아직 적용 대상이 아니다.

## 검증

정적 감사는 접근성의 완전한 증명이 아니다. 브라우저에서 모바일 패널 폭, 팝업 충돌, 목록 스크롤, 키보드, 모달 포커스, 검색 성공·실패와 지도 표시를 확인한다.
