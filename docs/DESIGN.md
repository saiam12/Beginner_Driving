# 차근차근 디자인 기준

## Overview

한국의 초보 운전자가 출발 전에 지역·거리·난이도를 선택하고 코스를 비교하는 제품 UI다. 기존의 흰 화면, 파란 선택 상태, 빨간 코스와 초록 출발 마커를 유지한다. 실제 네이버 지도와 사용자가 고른 코스의 연결이 중심이다. 홍보용 장식보다 지도와 조건의 가독성을 우선한다. 한국어(ko-KR)를 사용하며 일본 시장 전용 규칙은 적용하지 않는다.

CSS의 `:root` 변수가 색상과 지도 여백의 정식 소유자이며 이 문서는 그 값을 기록한다. `--color-primary`, `--color-text`, `--color-muted`, `--color-surface`, `--color-border`, `--map-inset`에서 공통 스타일로 이어진다. 기존 개별 상태 색은 단계적으로 정리하며, 지도 SDK 내부 스타일은 별도다.

## Colors

파랑은 선택과 주요 행동, 빨강은 선택 경로, 초록은 출발·도착이다. 본문은 text, 보조 설명은 muted를 사용한다. 색상만으로 선택을 전달하지 않고 라벨·테두리·aria-pressed를 함께 사용한다.

## Typography

Noto Sans KR을 본문과 제목에 사용하고 제목은 크기와 굵기로 구별한다. 기본 본문 14px, 일반 보조 문구 최소 12px, 제목 16~29px. 지도 위 지역명은 12px, 순위 숫자는 11px를 사용한다. 지도에는 점수 설명을 반복하지 않고 목록에서 제공한다. SDK의 저작권·축척 글자 크기는 제공자가 소유한다.

## Layout

데스크톱은 왼쪽 조건·목록과 오른쪽 지도다. 거리·난이도는 목록과 같은 스크롤 영역에 둔다. 화면 너비 900px 이하에서는 목록/지도 전환 버튼을 제공하고 각 패널을 전체 폭으로 표시한다. 두 패널은 마운트 상태를 유지해 지도 크기와 선택 상태를 보존한다.

데스크톱 사이드바 경계에는 세로 손잡이를 표시한다. 기본 폭 390px에서 320~560px까지 조절하며 지도에는 최소 420px을 남긴다. 모바일에서는 손잡이를 숨긴다. 드래그 중 지도 크기는 기존 ResizeObserver를 통해 갱신한다.

사이드바 내부 여백과 제목 크기는 컨테이너 폭에 따라 연속적으로 조절한다. 안내 그림은 SVG의 고정 viewBox를 사용하고 2:1 비율로 크기를 조절해 폭 경계에서 높이가 갑자기 바뀌지 않는다. 지역 버튼은 한 줄 이름과 동일한 높이를 유지하며 보조 화살표를 숨긴다. 드래그 폭 갱신은 애니메이션 프레임마다 한 번 적용한다.

지도 범례와 중앙 안내 카드는 데스크톱에서 하단 24px에 맞춘다. 모바일에서는 겹침을 피하기 위해 안내 카드를 84px로 올리고 범례는 24px를 유지한다. 좁은 데스크톱에서는 안내 카드가 범례 오른쪽에 배치된다.

## Elevation & Depth

코스 목록은 얇은 테두리로 구분하며 지도 위 카드와 모달에는 기존의 부드러운 그림자를 허용한다. 지도 위 UI가 경로의 대부분을 가리지 않도록 한다.

## Shapes

버튼·입력은 7px 전후의 둥근 모서리, 지도 카드에는 11px 모서리를 사용한다. 출발·코스 번호는 원형으로 지도 역할을 구분한다.

## Components

Header는 검색·지우기·도움말, DistanceControl은 거리·난이도, RouteCard는 코스 선택, RouteDetail은 상세 정보를 소유한다. MapView가 제공자를 선택하고 지도 컨트롤·범례는 두 제공자에서 같은 문구를 유지한다. Modal은 포커스 이동·가두기·Escape·복원을 소유한다.

### Iconography

lucide-react의 선 아이콘을 사용한다. 아이콘 전용 버튼에는 한국어 접근성 이름을 붙인다. 모바일 지도 컨트롤과 화면 전환 버튼은 최소 40~44px 높이를 사용한다.

### Motion

지도 SDK 이동 애니메이션은 상태 전환에 사용한다. 제품 CSS는 reduced-motion 환경에서 애니메이션·전환을 제거한다. SDK의 내부 움직임까지 완전히 제어한다고 보장하지 않는다.

지역 선택 시 지도의 중심과 배율을 약 1100ms 동안 함께 보간한다. 출발과 도착은 느리게, 중간은 자연스럽게 이동해 전국 지도에서 선택한 코스로 확대되는 흐름을 유지한다. 실제 지도 하나를 사용하며 reduced-motion 설정에서는 이 이동을 생략한다.

지도 위 출발·도착 문구, 코스 번호와 핀의 크기는 화면 기준으로 유지한다. 반 단계 줌에서도 글자를 지도 배율로 확대하지 않으며, 위치만 실제 좌표를 따라 이동한다.

### Ranking map

지역 순위는 126×36px의 한 줄 핀(순위 + 지역명)으로 표시한다. 핀 끝이 실제 지역 좌표를 가리키며 연결선과 큰 점수 카드를 사용하지 않는다. 순위가 높은 지역부터 충돌 없이 표시한다. 전국 수준에서는 데스크톱 최대 6개, 좁은 지도 최대 4개, 줌 10 이상에서는 각각 최대 10개/6개를 표시한다. 화면 밖·지도 컨트롤·범례와 충돌하는 지역명은 생략한다. 모든 지역은 왼쪽 목록에서 선택할 수 있다.

### Content and data visualization

검색이 가능한 예시 지역을 구체적으로 안내한다. 실제 분석이 연결되지 않은 점수·도로 지표는 예시로 표시한다. 지도 범례는 사용자가 요청한 추천 코스 / 출발 · 도착만 유지하며, 데이터 설명은 목록·상세·도움말에서 제공한다.

## Verification

데스크톱과 390px 모바일에서 검색·조건·코스 선택·상세·순위·모달을 확인한다. 키보드 Escape와 포커스 복원, 모바일 겹침, 지도 오류 재시도, 프로덕션 빌드 및 Premium 정적 감사를 점검한다.

## 실제 도로 검색 확장

검색의 시각 소유자는 기존 Header다. 기존 입력 높이·파란 강조·흰 표면·토큰을 유지하며 입력 아래에 제한 높이의 결과 패널을 둔다. 도로명, 실제 지역, 차로 범위·구간 수를 구분한다. 지도를 움직이면 실제 geometry 전체를 빨간 도로선으로 보여준다. LINK_ID는 지도 구간 정보와 펼친 상세 안에서만 표시한다. 실제 도로와 mock 추천 코스의 정보 카드는 구분한다.

## 지도 차로 선택

Header 우측의 LaneFilter는 1~6 및 7차로 이상의 선호 토글 버튼을 소유한다. 숫자를 일정한 폭으로 배열하고 선택 상태는 기존 primary 파랑과 aria-pressed로 표시한다. 미선택 차로도 후보에 포함하며 파란 전체 도로선을 그리지 않는다. 900px 이하에서는 검색 아래 전체 폭 한 줄로 차로 버튼을 배치한다. 지도 상태 안내는 위치 카드 아래에 두어 지도 컨트롤을 가리지 않는다.

차로 안내창 안의 ConnectedCourseControl은 실제 도로 거리 연결을 소유한다. 기존 희망 거리 값을 읽으며 거리 입력을 복제하지 않는다. 경로 형태와 추천 경로 선택은 기존 DifficultyControl의 버튼 선택 패턴과 aria-pressed를 따른다. 추천은 총 cost 순 상위 3·4·5개를 채택하며 버튼은 후보 번호로 표시하고 선택한 후보의 실제 거리는 결과 문구에 표시한다. 내부 거리대 분할은 사용자에게 노출하지 않는다. 선택한 경로만 빨간색으로 표시한다. 두 지도 제공자는 connected-course.js의 CONNECTED_COURSE_COLOR(#dc2626)를 공유하며 결과 문구와 선택 버튼도 같은 빨강을 사용한다. 실제 후보 표시 중 예시/검색 선과 예시 선택 카드는 숨긴다. 결과는 도로 연결 검토용이며 회전 제한과 현장 통제 미반영을 표시한다.

## 맞춤 연습 조건과 AI 추천

DriverPreferences는 기존 거리 조건 바로 아래에 같은 흰 표면·테두리·파란 선택 버튼으로 연습 목표를 배치한다. 운전 경험은 받지 않는다. 주행 목표 3개와 회피 상황 3개를 하나의 3열 목록으로 통합하며 회피 항목에는 피하기를 붙인다. 주행 목표 하나와 회피 항목 여러 개를 함께 선택한다. ConnectedCourseControl 안의 AI 행동은 150px 고정 폭이며 비교 근거는 실제 지표 문구로 짧게 표시한다. 후보 번호를 유지하고 파란 AI 추천 라벨을 추가하며 선택 경로의 빨강을 유지한다. 지도 상태 패널은 높이가 부족하면 자체 스크롤해 지도 컨트롤과 겹치지 않는다. 실패에서도 후보와 수동 선택을 유지한다. 별도 생성 AI 점수나 내부 거리대는 표시하지 않는다.

개발 단계에서는 전체 탐색 후보 목록을 접을 수 있는 details로 표시한다. 목록은 높이를 제한해 스크롤하며 각 후보는 네이티브 버튼이다. 총 cost·km당 cost·비용 구성과 채택 여부를 표시하고 채택된 경로를 함께 표시하며 선택한 경로는 진하게, 나머지는 반투명하게 표시한다. 동일 색/테두리/aria-pressed 선택 패턴을 사용한다. 이 개발용 비용 표시는 사용자가 요청한 진단 UI이며 서비스용 안전 점수로 해석하지 않는다.

출발 위치 설정은 실제 코스 안내창 최상단에 자동 선택/지도에서 지정/지도 중심으로 지정 네이티브 버튼 그룹으로 배치한다. 지도 선택 중에는 crosshair와 라이브 안내를 제공한다. 파란 원은 요청 위치, 기존 출발 마커는 도로에 연결한 실제 출발 위치다. 주소 검색과 위치 권한 없이 지도에서 지정하며 키보드 사용자는 지도 중심 지정 버튼을 사용할 수 있다. 지도를 강제로 이동하거나 배율을 바꾸지 않는다.

90% 경로 유사 제외 개수는 개발 전체 후보 제목의 총 발견 개수 옆에 표시하고, 제외 후보는 목록에서 숨긴다. cost 순 후보 번호는 유지하므로 추천 버튼 번호가 건너뛸 수 있다. 목록에는 유사 제외 후 유지된 후보만 표시하며 채택 여부와 비용을 검토할 수 있다.

채택 후보는 cost 순으로 비교해 상호 경로 일치율 40% 미만인 경로만 3~5개 표시한다. 후보 부족 시 실제 개수를 표시하며, 기존 90% 유사 제외와 개발 목록 기준은 유지한다.

연습 목표의 추가 항목 이름은 좌회전·유턴·좁은 도로로 간결하게 표시한다. 유턴 선택 시에만 동일 구간 왕복에 추가 비용을 적용한다.

지도에서 실제 후보 경로를 클릭하면 후보 버튼·개발 목록·거리 안내가 같은 선택으로 갱신된다. 선택 코스의 출발/도착 마커만 표시하고 기존 빨간색을 유지한다.

지도 위 코스 안내창은 오른쪽 위 −/+ 버튼으로 접거나 펼친다. 접힌 상태는 코스 후보 제목과 현재 배율만 표시해 지도를 가리는 면적을 줄이고, 탐색 결과와 선택 코스를 유지한다.

후보 번호는 실제 경로 위의 작은 배지로 상시 표시한다. 선택 배지는 빨간 배경, 비선택 배지는 흰 배경과 빨간 테두리다. 선택 경로에는 흰 외곽선의 빨간 방향 화살표를 둔다. 실제 출발/도착은 초록색 원과 연녹색 텍스트 배지로 표시하고 순환 시작·종료가 겹치면 출발 · 도착으로 합친다. 이 표기는 courseAnnotations.js를 공유하며 기존 파란 요청 위치와 구분한다.

후보 이름 배지는 선택 가능한 네이티브 버튼이며 클릭과 키보드 선택을 제공한다. 선택 색상과 번호는 기존 표기를 유지하고 hover 테두리와 공통 focus 링을 사용한다.
