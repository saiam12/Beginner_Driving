# 로컬 앱 코스 비용

현재 cost는 비교용 점수이며 화폐나 사고 확률이 아니다. 낮은 총 cost를 우선 탐색한다.

총 cost = 차로 기본 비용 + 사용자 선호 조정 + 교통량 비용 + 사고 비용 + 회전 비용.
유턴 연습 순환 코스의 반대 방향 재주행 비용은 사용자 선호 조정에 포함한다.

## 거리와 차로

거리는 도로 좌표 사이의 구면 거리 합계(m)이다.

| 차로 수 | 1m당 기본 cost |
| --- | ---: |
| 3·4·5차로 | 1 |
| 2·6차로 | 1.5 |
| 7차로 | 2 |
| 8차로 이상 | 2.5 |
| 1차로·미확인 | 3 |

선호 차로를 선택했을 때 선택하지 않은 차로는 1m당 3을 추가한다.
좁은 도로 연습을 선택하면 1차로는 1m당 0.75를 차감한다.
교차로 연습을 선택하면 인접 노드가 3개 이상인 출발 노드의 구간에서 차로 기본 비용의 15%를 차감한다.

## 회전

| 회전 | 기본 cost/회 | 해당 연습 목표 선택 시 |
| --- | ---: | ---: |
| 직진 | 0 | 0 |
| 우회전 | 50 | 15 |
| 좌회전 | 150 | 45 |
| 유턴 | 500 | 150 |

선택한 회전 목표에는 기본 비용의 70% 할인만 적용한다. 도로 진입·진출 방위각 차이가 30도 미만이면 직진, 150도 이상이면 유턴, 나머지는 방향에 따라 좌·우회전으로 추정한다. 신호나 표지의 공식 회전 판정은 아니다.
유턴 연습 목표가 있는 순환 코스에서 복귀 경로가 바깥 경로의 노드 연결을 반대로 다시 지나면 1m당 3을 추가한다. 같은 링크 재방문 전체에 일괄 적용하는 비용은 아니다.

## 교통량

교통량 지표 = (2024년 평일 추정 AADT / 24 / 차로 수) / 같은 시도 데이터의 최대 시간당·차로당 교통량.
교통량 cost = 주행거리(m) × 2 × min(1, 교통량 지표).
자료·기준값·기간이 맞지 않으면 지표는 미확인, 비용 추가는 0이다.

## 사고

대구 2024년 사고 6,440건을 15m 이내 최근접 Level 5.5 링크 1,874개에 각각 한 번 배정했다. 이 중 대구 도로망은 1,851개 링크·6,395건이며 인접 지역은 23개 링크·45건이다.

사고 밀도 r = 매핑 사고건수 / 원래 링크 길이(km).
연간 절대 사고건수가 12건 이상이거나, 사고건수가 3건 이상이면서 밀도 r이 30건/km 이상이면 경로 그래프에서 제외한다. 비용이 높아도 선택할 수 있는 후보로 남기지 않는다. 수동 출발·도착점을 연결하기 전에 제외하므로 링크를 잘라 기준을 피할 수 없다.

두 제외 조건에 해당하지 않을 때 사고 지표 = (2의 r/3 제곱 − 1) / (2의 20/3 제곱 − 1).
사고 cost = 주행거리(m) × 3 × 사고 지표.

지수항은 3건/km 증가마다 2배다. 1km 구간에 사고 3·6·9건이면 사고 비용은 각각 약 29.82·89.47·208.76으로 1:3:7이다. 연간 사고 12건 이상 또는 사고 3건 이상이면서 30건/km 이상이면 비용식과 관계없이 제외한다. 분모의 20건/km은 지수 비용의 정규화 기준이며 제외 기준이 아니다. 원래 링크 길이는 앱의 accidentLengthMeters를 사용하며, 일부만 주행하면 비용만 주행거리 비율로 반영한다.

대구 전체 3,743개 링크 중 106개(2.83%)가 제외 기준에 해당한다. 사고자료가 없는 1,892개 링크는 미확인으로 유지하며 실제 무사고로 해석하지 않는다. 미확인 구간의 사고 추가 비용은 0이므로 자료 적용 비율도 함께 확인한다.

현재 제외 기준과 지수식은 서비스 설계 정책이며 공식 위험등급이 아니다. 차량 통행량 노출 보정, 사망·부상 심각도 가중치와 사고유형 가중치는 아직 적용하지 않는다.

## 연습 목표의 횟수 비교

지도 형상의 진입·진출 방위각으로 좌회전·우회전·유턴 횟수를 센다. 신호나 도로 표지로 공식 판정한 횟수는 아니다.
후보 총 cost 범위를 3등분해 상대 난이도를 분류한다. 같은 난이도에서 일치하는 연습 목표 수가 같으면 선택한 회전 목표의 합계 횟수가 많은 후보를 우선한다. 좌회전만 선택하면 좌회전 7회인 후보가 1회인 후보보다 우선이다. 거리·사고 제외·중첩 기준을 통과한 후보에 적용하며 전체 후보를 회전 횟수 하나만으로 정렬하지는 않는다.

## 기타 조건

희망 거리 5~30km와 최소·최대 차이 10km 이내는 탐색 제한이며 별도 cost 항목이 아니다. 출발 위치까지 접근 거리와 예상 주행 시간도 cost에 포함하지 않는다. 제한속도·도로 폭·실시간 정체·보행자 밀도·날씨는 현재 cost에 포함하지 않는다.
유사 후보는 공통 링크 길이 기준으로 제외하며 최종 후보를 총 cost 순서로 비교한다. AI는 발견된 후보를 비교하고 설명한다. 경로의 기본 cost를 AI가 수정하지 않는다.
