## 검토 상태

비용 설계 변경사항을 관리하는 기록이다. 2026-10-13 기획서 수정본 차근차근_아이디어_기획서_9.docx에 반영했다. 프로그램에는 반영하지 않았다. 기존 기획서의 사고 밀도 기반 계단형 지수 비용을 대체하는 안으로 검토하며, 두 사고 비용을 중복 가산하지 않는다.

## 최신 사고 비용 기준 2건/km 단위 20% 복리 가산

기획서에 새로 반영할 사고 비용 기준은 아래의 2건/km 단위 20% 복리 가산 방식이다. 폐기된 계산식과 표는 이 기록에서 제외했다.

- `N`: 해당 도로 구간의 최근 5년 연평균 사고건수. 현재는 1년 자료만 확보되어 2024년 사고건수로 대체한다.
- 최근 5년 자료가 모두 있으면 `N = 5개 연도의 사고건수 합계 ÷ 5`로 계산한다. 자료가 없는 연도를 0건으로 채우거나 1년 사고건수를 5로 나누지 않는다. 현재 계산값을 실제 5년 평균으로 표시하지 않는다.
- `r`: 연평균 사고 밀도(건/km), `N ÷ 구간 전체 길이(km)`. 현재 계산 예시는 1년 자료를 대체 사용한 값이다.
- `x`: 사고 비용 계산에 사용하는 기준값(건/km)
- `k`: 적용 계단 번호
- `B`: 사고 가산 전 구간 기본 비용. 사용자 확인에 따라 차로 기본 비용과 교통량 비용의 합으로 정했다. 선호·연습 조정, 회전·재주행 비용은 포함하지 않는다.

### 적용 순서와 기준값

1. 실제 구간 길이로 계산한 사고 밀도가 `r ≥ 30건/km`이면 경로 후보에서 제외한다. 밀도 제외 조건에 별도의 최소 사고건수 하한을 두지 않는다.
2. 이전에 정한 사고건수 `N ≥ 12` 제외 조건은 이번 변경에서 삭제 지시가 없으므로 유지하여 기록한다. 이 조건의 유지 여부를 바꾸려면 별도로 정한다.
3. 제외되지 않은 구간의 비용 계산용 기준값을 정한다.
   - `N = 0`: `x = 0`
   - `0 < N ≤ 2`: `x = N`. 사고 1건이면 1건/km, 사고 2건이면 2건/km를 비용 계산용 기준값으로 사용한다.
   - `N > 2`: `x = r`. 사고 3건부터는 실제 구간 길이로 계산한 밀도를 사용한다.
4. 계단 번호는 `k = ceil(x ÷ 2)`로 정한다. `ceil`은 올림이며, 0 초과~2건/km는 1번째 계단, 2 초과~4건/km는 2번째 계단이다. 밀도 2.1건/km는 2번째 계단이며 정수로 먼저 반올림하지 않는다.

최근 5년 평균 N은 소수일 수 있다. 예를 들어 N이 2.4이면 `N > 2` 조건에 따라 밀도를 사용하며, N을 정수로 반올림해 분기하지 않는다. N이 2 이하일 때 사용한 x는 비용 계산용 값이며, 원본 사고 밀도로 표시하지 않는다.

밀도 제외 여부는 실제 r로 먼저 판단한다. 따라서 사고가 1·2건이어도 실제 밀도가 30건/km 이상이면 제외되며, 비용 계산용 x로 제외 기준을 우회하지 않는다.

### 계산식

- 사고 가산 후 구간 비용: `B × 1.2^k`
- 추가 사고 비용: `B × (1.2^k − 1)`
- 기본 비용 대비 증가율: `(1.2^k − 1) × 100%`

계단마다 직전 단계의 비용을 20%씩 복리 증가시킨다. 기본 비용의 20%를 계단 수만큼 단순 합산하는 방식과 다르다. 사고건수와 사고 밀도의 비용을 중복 적용하지 않는다.

| 조건 | 비용 계산용 기준값 x | 적용 계단 k | 사고 가산율 |
|---|---|---:|---:|
| N = 0 | 0건/km | 0 | 0.00% |
| 0 < N ≤ 2, 제외되지 않은 구간 | N을 기준값으로 사용 | 1 | 20.00% |
| N > 2, 밀도 0 초과~2건/km | 실제 밀도 | 1 | 20.00% |
| N > 2, 밀도 2 초과~4건/km | 실제 밀도 | 2 | 44.00% |
| N > 2, 밀도 4 초과~6건/km | 실제 밀도 | 3 | 72.80% |
| N > 2, 밀도 6 초과~8건/km | 실제 밀도 | 4 | 107.36% |
| N > 2, 밀도 8 초과~10건/km | 실제 밀도 | 5 | 148.83% |

N이 2를 초과하면 사고건수를 길이로 나눈 밀도로 비용을 계산한다. 사고 3건을 무조건 3건/km로 적용하던 이전 규칙은 사용하지 않는다.

밀도가 28 초과~30 미만인 구간은 15번째 계단을 적용한다. 가산 후 배율은 약 15.41배, 증가율은 약 1,440.70%다. 30건/km 이상이면 비용과 관계없이 제외한다. 20%는 실측 위험도나 사고 확률을 뜻하지 않는 설계 가중치다.

사고 12건 이상은 밀도와 관계없이 제외한다. 가산율은 추가 사고 비용의 비율이고, 배율은 기본 비용에 사고 가산 후 적용하는 비율이다. 예를 들어 가산율 44%는 기본 비용 1,000점에 440점을 더해 1,440점이 되는 것을 뜻한다.

## 경로 제외 조건

- 사고 밀도 `r ≥ 30건/km`이면 제외한다. 이전의 N ≥ 4 하한은 적용하지 않는다.
- 사고건수 `N ≥ 12` 제외 조건은 삭제 지시가 없으므로 기존 기준을 유지한다. N은 최근 5년 연평균을 원칙으로 하며 현재는 1년 자료를 사용한다.
- 연습 목표에 따른 비용 조정으로 제외 조건을 해제하지 않는다.
- 기존 97개(2.59%) 제외 집계는 최소 사고건수 하한이 있었던 이전 조건의 값이므로 새 기준의 결과로 사용하지 않는다. 자료 기간과 새 조건에 맞춰 제외 대상 수를 재계산해야 한다.


최소 사고건수 하한을 없앤 최신 제외 기준을 2024년 자료에 적용하면 사고 12건 이상 79개, 30건/km 이상 101개, 공통 1개로 총 179개(4.78%)다. 기존 후보 D는 사고 2건·길이 57.24m·밀도 약 34.94건/km인 명덕로 구간을 포함하므로 후보·지도·비교표에서 완전히 삭제한다. 제외 도로는 후보 생성 전에 탐색 대상에서 제거한다. 기획서 사례는 A·B·C 세 후보만 제시하며 최대 중첩 비율은 32.70%다. A~C의 km당 비용 순서는 B, C, A이며, 이 사례는 5년 평균이 아닌 2024년 1년 자료를 사용한다.

## 사고 비용 적용 요약

- 사고건수는 최근 5년 연평균을 원칙으로 한다. 현재는 자료 부족으로 1년 자료를 사용한 계산 예시다.
- N이 2 이하인 구간은 N을 비용 계산용 기준값으로 사용한다.
- N이 2를 초과하는 구간은 구간 전체 길이로 보정한 밀도를 사용한다.
- 비용 계산용 기준값을 2건/km 단위로 올림하고 계단마다 20% 복리 가산한다.
- 가산 전 기본 비용 B는 차로 기본 비용과 교통량 비용의 합이다.

## 대구 사례의 사고자료 기간 설명

기획서의 대구 경로 비교 사례 중 사고자료 소개 부분에 다음 문구를 넣는다. 최근 5년 평균이라는 서비스 설계 기준과 1년 자료를 사용한 사례를 구분하며, 확보하지 못한 연도를 0건으로 처리하지 않는다.

> 서비스의 사고건수는 최근 5년간의 연평균을 기준으로 산정하도록 설계한다. 다만 대구 경로 비교 사례에서는 확보한 사고자료가 2024년 자료에 한정되어, 해당 연도 1년치 사고건수로 사고 밀도와 비용을 계산하는 예시를 제시한다. 이 사례의 수치는 최근 5년 평균을 뜻하지 않는다.

자료 기간의 제한은 사고자료에 대한 설명이다. 도로·교통량 등 다른 자료도 1년치만 확보했다는 뜻으로 확대해서 쓰지 않는다.

## 기획서 반영 전에 결정할 사항

- 구간 일부만 주행할 때의 적용 방식
- 사고 자료가 없는 구간의 표시와 계산 처리
- 구간 분할에 따라 사고건수와 비용이 달라지는 영향

구간 일부만 주행하더라도 사고 기준값과 제외 여부는 원래 구간의 사고건수·전체 길이를 기준으로 판단할 계획이다. 구간 기본 비용 B에는 실제 주행 길이를 반영하고, 선호·연습 조정과 회전·재주행 비용은 별도로 더한다. 이 방식으로 후보 사례를 계산해 기획서 수정본에 반영했다.

## 회전 비용 반영 대기 기준

2026-10-13 사용자 변경사항에 따라 다음 단가로 기록한다. 기획서 수정본에는 반영했으며 프로그램에는 아직 반영하지 않았다.

| 회전 종류 | 1회당 비용 | 상대 가중치 |
|---|---:|---:|
| 우회전 | 500점 | 2 |
| 좌회전 | 250점 | 1 |
| 유턴 | 1,000점 | 4 |
| 직진 | 추가 비용 0점 | 0 |

회전 비용은 `우회전 횟수 × 500 + 좌회전 횟수 × 250 + 유턴 횟수 × 1,000`으로 계산한다. 이 값은 비교를 위한 설계 가중치이며 실측 사고 위험도 비율을 뜻하지 않는다.

이전 우회전 250·좌회전 500·유턴 1,000 단가와 합산 회전 비용 비중 19.64%는 최신 단가의 결과로 사용하지 않는다. 새 사고 가산 기준과 회전 단가를 함께 적용한 후보 계산 결과는 기획서 수정본에 제시한다. 사용자 확인에 따라 기존 연습 목표 선택 시 해당 회전 비용 70% 감소 정책을 유지한다. 우회전 연습은 150점/회, 좌회전 연습은 75점/회, 유턴 연습은 300점/회를 적용한다.
