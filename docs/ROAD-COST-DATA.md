# 교통량·사고 비용 입력 계약

현재 도로망은 View-T 2024년 Level 5.5 원본이다. 전처리 과정에서 같은 해의 교통량을 같은 Level 5.5 ID에 직접 연결하고 도로명·차로·등급·시도·원본 길이를 대조한다. 전국 119,466개 구간 중 119,413개가 교통량을 가지며 나머지 53개는 미확인이다. ITS 대응이나 별도 로더 보정은 사용하지 않는다.

`scripts/preprocess-level55-roads.py`가 검색 형상과 공간 타일에 동일한 비용 속성을 생성한다. `src/lib/road-data-cost.js`가 이를 읽으며 Worker와 저장 코스가 비용 내역과 관측 비율을 보존한다. AADT/24를 시간당 평균 대리값으로 사용하고, 비교 기준도 같은 시도 전체 자료의 차로당 AADT 최댓값/24로 변환한다. 특정 시간대 교통량이나 실시간 혼잡도를 뜻하지 않는다.

## 필요한 속성

| 속성 | 의미 |
|---|---|
| trafficVolume | 해당 방향 LINK의 시간당 교통량(대/시간). View-T 연평균 평일 AADT는 AADT/24 대리값이며 특정 시간대 관측값이 아니다. 전체 방향 합계나 이미 차로로 나눈 값을 입력하지 않는다. |
| trafficPeriod | 관측 조건 식별자. 날짜 범위·요일·시간대 등을 포함해 구분한다. |
| trafficPerLaneReference | 비교 가능한 도로 집단의 차로당 교통량 기준(대/시간/차로). 현재 기준: 같은 시도 전체 유효 자료의 차로당 AADT 최댓값/24. |
| trafficReferencePeriod | 교통량 기준을 산출한 관측 조건. trafficPeriod와 일치해야 한다. |
| accidentCount | 이 LINK에 배정된 사고 건수. 0 이상의 정수. 한 사고를 겹치는 LINK에 중복 배정하지 않는다. |
| accidentPeriod | 사고 집계 기간 식별자. |
| accidentsPerKmReference | 동일 기간·비교 가능한 도로 집단의 km당 사고 건수 기준. |
| accidentReferencePeriod | 사고 기준의 집계 기간. accidentPeriod와 일치해야 한다. |

비교 기준은 현재 화면의 도로만으로 즉석 산출하지 않고, 실제 자료를 준비할 때 비교 집단 전체에서 산출한다. 교통량과 사고의 서로 다른 관측 기간은 허용하지만 각 관측값과 해당 기준의 기간은 같아야 한다. 코드의 기간 일치 검사는 집단/도로 등급/방향/측정 방식이 비교 가능한지까지 검증하지 않으므로 데이터 병합 단계에서 확인해야 한다.

## 계산

```text
차로당 교통량 = trafficVolume / LANES
교통량 점수 = min(1, 차로당 교통량 / trafficPerLaneReference)
km당 사고 = accidentCount / (지도 구간 길이 / 1000)
사고 점수 = min(1, km당 사고 / accidentsPerKmReference)

교통량 비용 = 구간 길이 × 2 × 교통량 점수
사고 비용 = 구간 길이 × 3 × 사고 점수
총 경로 비용 = 차로 비용 + 차로 선호 비용 + 교통량 비용 + 사고 비용 + 회전 비용
```

초기 가중치 2/3은 `ROAD_DATA_COST_WEIGHTS`가 소유하며 학습이나 실제 사용자 검증으로 결정된 값은 아니다. 사고 지표는 기간별 사고 밀도이며 통행량을 보정한 사고 확률이나 안전 보장이 아니다. 추후 노출량·심각도 자료가 확보되면 지표를 별도로 보완한다. 실제 주행거리는 비용과 분리한다.

미관측/잘못된 값/비교 기준 누락/기간 불일치에는 점수 `null`, 추가 비용 0을 반환한다. 이때는 낮은 교통량·사고 0건으로 판단한 것이 아니라 해당 항목의 비용 적용을 보류한 것이다. 유효한 실제 0은 점수 0으로 구분한다. 음수·문자열·NaN·Infinity·0 이하 기준·차로 0·음수 길이를 비용으로 반영하지 않는다.

경로 결과의 `costBreakdown`은 lane/preference/traffic/accidents/turns별 비용, `dataCoverage`는 주행거리 중 유효한 교통량/사고 데이터가 적용된 비율(0~1)을 제공한다. 데이터가 일부만 있는 경우 미확인 구간을 저위험으로 설명해서는 안 된다. 현재는 비용을 중립으로 두므로 자료가 없는 경로가 유리해질 수 있으며, 실제 자료 연결 때 관측 범위와 미확인 구간 정책을 함께 정해야 한다. 사용자 화면에는 비용 수식이나 내부 거리대 분할을 추가하지 않는다.

## 검증

`npm run test:connected`: 차로당 교통량, 사고 밀도·비용, 유효 0과 미관측 구분, 잘못된 값·기준·기간 거부, 관측 비율, 데이터에 따른 경로 선호 변경, 비용 합산과 실제 거리 보존을 검증한다.
`npm run test:level55`는 전국 데이터 직접 연결, 실제 로더와 후보 비용, 원본 방향·형상, 서울 코스와 저장 ID를 검증한다. 사고 자료 연동은 아직 수행하지 않았다.
